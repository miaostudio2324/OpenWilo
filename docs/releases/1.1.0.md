## English

OpenWilo 1.1.0 adds a full English interface alongside the Simplified Chinese edition. The English edition includes the channel charts, scanning controls, filters, network details, decoded information elements, and session tools.

Requires macOS 14 or later. Extract the ZIP and open `OpenWilo.app`. The app interface uses the language selected at download. macOS-provided controls may use the system language. Saved JSON sessions can be opened in either edition.

## 简体中文

OpenWilo 1.1.0 在简体中文版之外新增英文版，覆盖信道图、扫描控制、筛选、网络详情、信息元素解码和会话工具。请在上方表格选择语言和芯片架构。

需要 macOS 14 或更高版本。解压 ZIP 后打开 `OpenWilo.app`。应用界面使用下载时选择的语言，macOS 提供的控件可能随系统语言显示。两个版本均可打开已保存的 JSON 会话。

### Build and integrity / 构建与校验

Release builds are ad hoc signed. SHA-256 checksum files are available alongside the ZIPs.

发布包使用 ad hoc 签名，旁边附有各 ZIP 对应的 SHA-256 校验文件。
