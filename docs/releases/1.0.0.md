## OpenWilo 1.0.0

The first public release of OpenWilo, a native Wi-Fi channel analyzer for macOS.

- View 2.4, 5, and 6 GHz channel usage with adaptive RSSI axes and SSID labels.
- Scan continuously, compare access points, inspect 802.11 information elements, and view the current Wi-Fi transmit rate.
- Save local JSON sessions and export selected or filtered networks as CSV.

The attached ZIPs support Apple silicon (arm64) and Intel Macs (amd64 / x86_64) running macOS 14 or later. Both builds are ad hoc signed and have no Apple notarization. Location permission enables access to SSIDs and BSSIDs.

## 简体中文

OpenWilo 的首个公开版本是一款 macOS 原生 Wi-Fi 信道分析器。

- 查看 2.4、5、6 GHz 信道分布，支持自适应 RSSI 刻度和 SSID 标签。
- 连续扫描、对比接入点、检查 802.11 信息元素，并查看当前 Wi-Fi 发送链路速率。
- 在本地保存 JSON 会话，将所选或筛选结果导出为 CSV。

安装包分为 Apple 芯片版（arm64）和 Intel 版（amd64／x86_64），均需要 macOS 14 或更高版本。两个版本均使用 ad hoc 签名，未经过 Apple 公证。允许定位权限后可读取 SSID 和 BSSID。
